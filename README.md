# 🌰 도토리하루 매니저 v1.2

성빈 님의 네이버 블로그 '도토리하루'(binifilm)와 인스타그램 @dotori_haru를 폰에서 한 손으로 관리하는 모바일 웹앱입니다.
`index.html` 하나로 열리며, 아이폰 사파리에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

---

## 1. 파일

| 파일 | 역할 |

## 2. 여는 방법

**폰에서 바로 보기 (가장 간단)**
1. `index.html`을 아이폰으로 보내 사파리에서 엽니다 (파일 앱 → 공유 → 사파리).
2. 숫자·포스팅 기록은 이 브라우저에만 저장됩니다.

**앱처럼 쓰기 (권장)**
1. 이 폴더를 GitHub Pages 등에 올립니다.
2. 사파리에서 주소를 열고 **공유 → 홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 열립니다. (오프라인 캐시도 이때 켜져요.)

> `file://`로 열면 브라우저 보안 규칙 때문에 `data.json`을 읽지 못합니다. 이때는 "자동 연동 없음 · 직접 기록으로 보여드려요"라고 표시되고, 직접 입력한 기록만으로 정상 동작합니다 (오류 없음).

## 3. 들어 있는 기능 (하단 탭 4개)

### 📈 성장 트래커 (1번째 탭)
- **오늘 포스팅 카운터** — `포스팅 완료 +1` 버튼 한 번으로 오늘 개수 기록, `−`로 정정. 이번 주 · 이번 달 누적과 연속 기록 일수를 배지로 보여줍니다.
- **포스팅 달력** — 월 단위 달력에서 날짜별 개수를 색으로 표시합니다 (1개 연한 민트 → 2개 → 3개 이상 진한 민트). 지난 날짜를 누르면 그 날 개수를 고칠 수 있고, 오늘은 점선 테두리로 표시됩니다. 미래 날짜는 잠겨 있어요.
- **직전 보름 대비** — 블로그 토탈 방문자 / 이웃 / 애드포스트 수익 / 인스타 팔로워를 직전 기록과 비교해 `+1,280 +10.3%` 같은 배지로 보여줍니다.
- **성장 추이 그래프** — 방문자·이웃·수익·팔로워를 탭해서 전환, 최근 8회 기록을 SVG 선그래프로 그립니다 (외부 라이브러리 없음).
- **기록 추가/수정/삭제** — 보름 단위(1일·15일)로 숫자를 넣습니다. 같은 날짜 중복은 막아 줍니다.
- **샘플 데이터 안내** — 처음 두 개는 예시이며 "샘플" 배지가 붙습니다. `샘플 지우기`를 누르면 사라지고, 연필 아이콘으로 바로 고칠 수도 있어요.
- **백업·복원** — JSON 파일로 내보내고 복원합니다 (기록·포스팅·체크리스트·협찬·재활용 보드·카드뉴스 설정 전부).

### ✏️ 제목·태그 (2번째 탭)
- 카테고리(맛집/카페/국내여행/상품리뷰/일상) + 지역·장소명 + 핵심 포인트(3개까지)를 고르면
- `지역+카테고리ㅣ감성 후킹 문구` 형식의 제목 3종을 만들고, 각각 복사 버튼을 제공합니다. `다른 제목`으로 계속 뽑을 수 있어요.
- 상위 노출용 태그 **15개**를 `#해시` / `쉼표` 형식으로 전환해 복사할 수 있습니다 (발행 패널의 태그 편집란에 넣는 용도).
- 발행 전 서식 5가지 체크리스트 요약이 함께 나옵니다.

### 📋 체크·캡션 (3번째 탭, 세그먼트 3개)
- **캡션 템플릿** — 릴스 / 피드·카드뉴스 / 스레드(500자 카운터) 3종. 장소와 핵심 한 줄, 감성 한 줄을 넣으면 마크다운 별표·온점 없이 이모지와 줄바꿈만 쓴 캡션이 나옵니다. 저장 CTA와 해시태그가 자동으로 붙고, 나온 글은 직접 고쳐서 복사할 수 있어요.
- **엔딩 체크** — 도토리하루 모바일 서식 8가지 + 엔딩 5단계(한줄요약 스티커 → 한줄요약 멘트 → 내돈내산 카드 → 마무리멘트 → 귀여운 스티커) + 발행 전 5가지. 체크 상태는 자동 저장됩니다.
- **협찬 기록 (체험단 협찬·협업 트래커)**
  - 위쪽 카드에 **총 협찬 누적 금액**과 총 건수(리뷰완료/진행중), **맛집 · 숙소 · 배송형** 각각의 금액·건수를 한눈에 보여줍니다.
  - `전체 / 맛집 / 숙소 / 배송형` 필터로 목록을 나눠 봅니다.
  - 항목명 · 다녀온 날 · 카테고리 · 협찬 금액(원) · 상태(진행중/리뷰완료) · 메모를 넣고 **추가 · 수정 · 삭제**(2단계 확인)합니다. 전부 LocalStorage에 자동 저장.
  - **CSV 내보내기** — 엑셀에서 바로 열리도록 UTF-8 BOM + CRLF로 저장하고, 마지막에 총합계·카테고리별 소계 행을 넣습니다. (엑셀로 정리하시던 목록을 이어가시면 됩니다.)
  - 예전 '체험단 메모'가 남아 있으면 앱을 처음 열 때 한 번만 협찬 기록으로 옮겨 담고 `이전 메모` 배지로 표시합니다 (카테고리는 '맛집', 금액은 0원으로 두니 확인 후 고쳐 주세요).

### ♻️ 재활용 (4번째 탭, 세그먼트 2개)

**① 재활용 보드 — 블로그 → 인스타 1+1**
- 발행한 글의 **제목 · 발행일 · 링크(메모)** 를 등록하면 글마다 **카드뉴스 / 스레드 / 릴스** 3가지 2차 가공 여부를 원터치 토글로 체크합니다. 누르는 즉시 저장돼요.
- 위쪽 요약 배지에 `재활용 완료 N건 · 아직 남은 글 M건`, 전체 진행률 바, 종류별 `카드뉴스 3/4` 같은 칩을 함께 보여줍니다.
- `data.json`에 `postsList`(또는 `recentBlogs`) 배열이 있으면 자동으로 불러와 병합합니다. 자동으로 들어온 글은 `자동` 배지가 붙고, 처음 토글하면 내 기록으로 옮겨 담습니다(자동본은 숨김 · `숨긴 자동 글 되돌리기`로 복구).

**② 카드뉴스 만들기 — HTML5 Canvas → 1080×1350 PNG**
- 폰 사진첩에서 사진 1장을 고르고 → 스타일 3종(① 매거진 풀샷 커버 ② 크림 프레임 ③ 라벨 포인트)과 글꼴 3종(주아 / 둥근 고딕 / 나눔스퀘어) 중에서 고르고 → 제목 · 한 줄 요약 · 하단 태그(`@dotori_haru`)를 입력하면 **실시간 미리보기**가 그대로 나옵니다.
- `[이미지 저장하기]`를 누르면 **1080×1350px PNG**를 만들어 내려받습니다. 아이폰에서는 공유 시트(사진에 저장)를 쓰거나 완성 이미지를 길게 눌러 저장하면 됩니다.
- 사진은 고른 동안만 메모리에 있고 저장되지 않습니다(글·스타일·글꼴만 기억). 사진이 없어도 파스텔 배경으로 카드를 만들 수 있어요.

### 🔒 PIN 잠금 (선택 · 헤더 오른쪽 자물쇠 버튼)
- 기본은 **꺼짐**이라 처음엔 바로 열립니다. 자물쇠 버튼 → 4자리 숫자를 두 번 입력하면 켜집니다.
- 켠 뒤로는 앱을 열거나 새로고침할 때 파스텔 **PIN 입력 화면**이 먼저 뜨고, 맞춰야 내용이 보입니다. 5번 틀리면 15초 동안 잠깐 막아 둡니다.
- 같은 시트에서 **현재 PIN을 확인한 뒤 PIN 변경 / 잠금 해제**를 할 수 있습니다.
- PIN은 단방향 해시(+설치마다 다른 salt)로 **이 기기 브라우저에만** 저장되고 어디로도 보내지 않습니다. 화면을 가리는 보조 장치이니 폰 자체 암호와 함께 쓰시는 게 좋아요. **PIN을 잊으면 브라우저 데이터를 지워야 풀리고, 그때 기록도 함께 지워집니다.**

## 4. `data.json` 자동 연동 (매일 갱신용)

앱은 켜질 때 같은 폴더의 `data.json`을 `fetch('./data.json')`으로 읽어 성장 기록·포스팅 달력·재활용 보드에 자동으로 합쳐 보여줍니다. 파일이 없거나 읽지 못하면 조용히 직접 기록만 사용합니다 (화면에 "자동 연동 없음"으로 표시).

```json
{
  "schemaVersion": 1,
  "source": "binifilm",
  "updatedAt": "2026-11-16T09:00:00+09:00",
  "records": [
    { "date": "2026-11-01", "blog": 12480, "neighbor": 842, "adpost": 18600, "insta": 1310 },
    { "date": "2026-11-15", "blog": 13760, "neighbor": 867, "adpost": 24100, "insta": 1362 }
  ],
  "posts": [
    { "date": "2026-11-14", "count": 2, "titles": ["순천 1박 2일 총정리", "진천 안나의 화원"] },
    { "date": "2026-11-15", "count": 1 }
  ],
  "postsList": [
    { "date": "2026-11-14", "title": "순천 1박 2일 뚜벅이 총정리", "link": "https://blog.naver.com/binifilm/223456789" },
    { "date": "2026-11-15", "title": "시골 김장 후기", "link": "", "done": { "card": true, "thread": false, "reels": false } }
  ]
}
```

- `records[]` — 보름 단위 성장 기록. `date`(YYYY-MM-DD)와 `blog`(토탈 방문자), `neighbor`(이웃), `adpost`(원), `insta`(팔로워). 별칭도 인식합니다(`visitors`, `neighbors`, `revenue`, `followers`).
- `posts[]` — 날짜별 포스팅 수. `{"2026-11-14": 2}` 같은 객체 형식도 됩니다. `titles`가 있으면 재활용 보드의 후보 글로도 쓰입니다.
- `postsList[]` — 재활용 보드용 발행 글 목록. `title`(필수), `date`, `link`, 그리고 선택으로 `done: { card, thread, reels }`. `recentBlogs`·`blogPosts`라는 이름도 인식합니다.
- `updatedAt` — 이 파일을 마지막으로 갱신한 시각. 달력 위에 `11/16 09:00 업데이트`로 표시됩니다.

**합치는 규칙**
- 성장 기록: 성빈 님이 직접 넣은 값이 항상 우선이고, 비어 있는 날짜만 `data.json` 값이 채웁니다 (자동으로 채워진 줄에는 `자동` 배지).
- 포스팅 개수: 성빈 님이 손으로 누른 날짜가 우선, 나머지 날짜는 `data.json` 값을 씁니다.
- 재활용 보드: 같은 날짜+제목의 글은 한 번만 보여주고, 성빈 님이 체크한 기록이 우선입니다. `data.json`에서 온 기록을 지우면 숨김으로 기억합니다.
- `data.json`에서 온 기록을 지우면 그 날짜는 숨김으로 기억하고, 백업 카드의 `숨긴 자동 기록 되돌리기`로 복구할 수 있습니다.
- 달력 위 `새로고침`을 누르면 파일을 다시 읽습니다 (앱을 새로 열어도 자동으로 읽어요).

**⚠️ `data.json`에는 개인 데이터를 넣지 않습니다**
- 이 저장소에 올라가는 `data.json`은 **항상 비어 있는 기본값**으로 둡니다 (`records: []`, `posts: []`).
- 수익·협찬 내역·메모·카드뉴스 글 같은 개인 기록은 **이 기기 브라우저의 LocalStorage에만** 저장되고 어디로도 전송되지 않습니다.
- `data.json`에 공개 블로그에서 확인되는 숫자(방문자·이웃·글 제목)만 자동으로 채우는 것도 선택 사항이며, 필요 없으면 그대로 비워 두세요.

**매일 갱신하는 쪽(자동화)에서 할 일**
1. 공개 블로그 `blog.naver.com/binifilm`에서 그날 발행 글 수(과 필요하면 방문자·이웃 수)를 확인합니다.
2. `data.json`의 `posts`(과 `records`, 원하시면 `postsList`)에 해당 날짜를 추가하고 `updatedAt`을 현재 시각으로 바꿉니다.
3. 같은 폴더에 배포(GitHub Pages 등)하면 다음에 앱을 열 때 자동 반영됩니다.
